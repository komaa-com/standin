# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities **privately**. Use GitHub's **"Report a vulnerability"**
button under this repository's **Security** tab (private vulnerability reporting) rather than
opening a public issue.

Include a clear description, reproduction steps, and the affected component. We aim to acknowledge
reports within a few business days and will keep you informed through remediation and coordinated
disclosure.

## Scope

This repository is the StandIn overview. If your report concerns a specific bridge, you can also
file it privately on that bridge's own repository (each backend in the README table links to its
source). For anything touching the hosted service at standin.komaa.com, private reporting here is
the right channel.
