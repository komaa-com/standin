# Contributing

This repository is the front door for StandIn: the overview, the backend table, and the quickstart.
The code lives in the per-backend bridge repositories, so that is where issues and pull requests
are most useful. Each backend name in the README table links to its repository.

Good places to contribute:
- A bug or feature request for a specific bridge: open it on that bridge's repository.
- A mistake or improvement in this overview: open an issue or PR right here.
- Questions about the hosted service: [standin.komaa.com](https://standin.komaa.com) or the docs at
  [docs.komaa.com](https://docs.komaa.com).
